# Projeto de estudos
Esse projeto consiste em um repositório de estudos. A ideia veio de ajudar minha irmã a organizar todo o conteúdo que ela precisa estudar para se preparar para processos seletivos para o ensino médio e para escolas de nível técnico.
<br> É basicamente um "site" com todas as fontes que ela pode usar pra salvar o conteúdo, com links de videos, imagens e conteúdo em texto.
# StudyProject
That project consists in a repository of studying. The idea became from helping my sister organizing the contents she got to study to prepare herself for selective processes from high school and technical schools.
<br> It basically is a "website" with all the fonts that she can use to save the content, with videos links, images and text content.
